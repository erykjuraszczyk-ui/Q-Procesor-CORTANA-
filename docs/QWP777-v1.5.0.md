# QWP-777 v1.5.0

## Release contents
1. `src/qwp777_conformance_suite.py` runs six built-in golden-circuit checks.
2. `src/qwp777_suite.py` exposes the conformance suite as a command-line tool and can write a JSON report.
3. `src/qwp777_significance.py` implements an independent two-sample Pearson chi-square test with a conservative expected-cell-count guard.
4. `src/qwp777_compare.py` emits a complete result-comparison report with confidence intervals and significance analysis.
5. Experiment result schema remains `qwp777-experiment-1`. Comparison report schema is `qwp777-experiment-report-1`.

## Conformance suite
```bash
python src/qwp777_suite.py
python src/qwp777_suite.py --shots 512 --seed 1777 -o conformance-report.json
```

The suite checks:
- all-zero measurement from the initial state;
- deterministic Pauli-X measurement;
- Bell-state correlations;
- three-qubit GHZ correlations;
- broad sampling balance after a Hadamard gate;
- the endpoint of the synthetic bit-flip model (`p=1`).

These are fixed-seed software checks, not hardware certification or an exhaustive proof of correctness.

## Statistical comparison and full report
```bash
python src/qwp777_experiment.py examples/bell.json -o /tmp/a.json
python src/qwp777_experiment.py examples/bell.json --noise-probability 0.02 -o /tmp/b.json
python src/qwp777_compare.py /tmp/a.json /tmp/b.json --confidence-level 0.95 --alpha 0.05 -o comparison-report.json
```

The report contains input metadata, TVD, Hellinger distance, per-outcome probability deltas, Wilson intervals, chi-square statistic, degrees of freedom, p-value when appropriate, assessment, and caveats.

## Significance decision
- `difference_detected`: calculated p-value is below alpha.
- `no_significant_difference_detected`: calculated p-value is not below alpha; this is not proof of equivalence.
- `inconclusive`: insufficient categories or any expected chi-square table cell is below 5, so the asymptotic test is not used.

The Pearson test assumes independent samples and an appropriate common categorical outcome space. The p-value is not adjusted for multiple comparisons. Statistical evidence does not prove either backend correct or determine the cause of a difference.

## Known scope limits
QWP-777 remains a software prototype, not physical quantum hardware. Synthetic bit-flip noise is post-processing, not calibrated device noise. The statevector reference is limited to 12 qubits, the stabilizer backend targets supported Clifford circuits, and the project does not claim universal simulation of arbitrary circuits on 777 qubits.
