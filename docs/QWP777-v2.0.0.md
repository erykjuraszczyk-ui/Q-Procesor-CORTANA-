# QWP-777 v2.0.0

## Release scope
- API contract generation 2.0 with versioned snapshot `compatibility/api-v2.0.0.json`.
- Legacy public API checks against v1.6.0 remain enabled.
- Unified release audit checks current and historical contracts, fixed-seed regressions, checksums, release comparison, and signing self-tests.
- Versioned regression baseline `regression/baselines/v2.0.0.json`; older baselines remain unchanged.
- Experiment result schema remains `qwp777-experiment-1`; public exports and signatures are preserved.

## Run tests and audit
```bash
python -m unittest discover -s tests -v
python src/qwp777_api_compat.py --contract compatibility/api-v2.0.0.json -o api-v2-contract-report.json
python src/qwp777_release_audit.py -o docs/RELEASE_AUDIT.json
```

The audit is a finite test report, not formal verification. QWP-777 is educational software, not physical quantum hardware, and does not claim to simulate every arbitrary circuit on 777 qubits. The optional Qiskit Aer comparison is not part of the default audit.
