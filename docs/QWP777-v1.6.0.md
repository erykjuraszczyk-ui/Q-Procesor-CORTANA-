# QWP-777 v1.6.0

## Release additions
1. **Regression suite:** `src/qwp777_regression.py` executes six fixed-seed circuits against saved counts captured using v1.5.0.
2. **Optional external backend comparison:** `src/qwp777_backend_compare.py` compares built-in and Qiskit Aer empirical distributions when Qiskit Aer is installed.
3. **Report/configuration archiving:** `src/qwp777_archive.py` stores the report, original input configuration, checksum manifest, and ZIP package.
4. API version 1.6; experiment result format remains `qwp777-experiment-1`.

## Regression suite
```bash
python src/qwp777_regression.py
python src/qwp777_regression.py -o regression-report.json
```
The bundled baseline at `regression/baselines/v1.5.0.json` captures exact counts for a zero state, X state, Bell state, three-qubit GHZ state, Hadamard sampling, and a 2% synthetic-noise case. It uses exact count comparison for fixed seeds. If simulation behavior intentionally changes, review and version the baseline rather than silently replacing it.

## Optional Qiskit Aer backend
```bash
python src/qwp777_backend_compare.py examples/bell.json -o backend-comparison.json
```
When Qiskit Aer is unavailable, the tool produces `optional_backend_unavailable` and an actionable message instead of claiming a comparison occurred. When available, the report includes both counts and empirical distribution-distance metrics. If `--noise-probability` is supplied, the same synthetic post-processing setting is applied to both outcome samples. The noise option is not a calibrated device-noise model.

## Archive a report with its configuration
```bash
python src/qwp777_archive.py backend-comparison.json --config examples/bell.json --archive-dir reports/archive
```
Each archive contains `report.json`, `configuration.json`, and `manifest.json`, and is packaged as a ZIP. The manifest records SHA-256 and byte lengths for the two input artifacts. Names are validated and existing archives are not overwritten.

## Limitations
Regression tests cover known saved cases, not all possible circuits. Counts can change if random-number generation or simulator logic changes, and such changes require explicit baseline review. Statistical comparisons between independent simulators are empirical rather than proof of mathematical equivalence. Qiskit Aer runs on classical computing hardware. QWP-777 remains a software prototype, not a physical quantum processor, and does not universally simulate arbitrary circuits on 777 qubits.
