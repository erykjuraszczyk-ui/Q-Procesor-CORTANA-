# QWP-777 v2.4.0

## Cel wydania

Wydanie dodaje heurystyczną analizę anomalii pamięci w raportach soak oraz porównanie tego samego obciążenia uruchomionego na różnych urządzeniach. Nie zmienia eksportów publicznego API ani schematu wyników `qwp777-experiment-1`.

## Nowe narzędzia

- `src/qwp777_stability_analyze.py` analizuje trendy `tracemalloc` i, gdy dostępne, RSS. Ostrzeżenia są kandydatami do dalszej diagnostyki, nie dowodem wycieku pamięci.
- `src/qwp777_device_compare.py` porównuje raporty soak o tym samym obwodzie, liczbie strzałów, ziarnie bazowym i ustawieniach szumu.
- Kontrakt API `compatibility/api-v2.4.0.json` oraz nowa baza regresji `regression/baselines/v2.4.0.json`.

## Ograniczenia

RSS jest najlepszym możliwym odczytem z systemu i może być niedostępny. `tracemalloc` nie mierzy całej pamięci procesu. Porównania różnych urządzeń są opisowe; sprzęt, temperatura, polityka zasilania i procesy w tle wpływają na wynik. Krótki test nie dowodzi obecności ani braku wycieku pamięci.
