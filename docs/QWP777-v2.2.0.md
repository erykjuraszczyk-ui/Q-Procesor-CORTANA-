# QWP-777 v2.2.0

## Goals
Reduce avoidable per-shot memory allocations and introduce safe scaling diagnostics while preserving the public experiment result schema.

## Implementation
- `StabilizerSimulator.run(..., include_tableau=True)` preserves existing default return values; `run_experiment` passes `False` to avoid a redundant copy of all tableau rows per shot.
- `qwp777_memory.py` estimates list-container sizes for the internal X/Z matrices and phase vector.
- `qwp777_benchmark.py` runs a GHZ-style Clifford workload over bounded qubit and shot lists; records per-case times and a separate traced-memory sample.
- Unified release audit validates API contracts, regressions, signatures, memory-estimator monotonicity and benchmark smoke cases.

## Validation boundaries
Benchmarks are diagnostic, not proof of universal speedup. The container-memory estimate is not process RSS. Physical Android/Termux measurements remain to be collected by running the package on the target phone. QWP-777 is not physical quantum hardware.
