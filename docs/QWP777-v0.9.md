# QWP-777 v0.9.0 — Technical Specification

## Objective
Provide a repeatable experiment interface around the v0.8 stabilizer prototype and a small set of statistical metrics for comparing observed and reference outcome distributions.

## Experiment lifecycle
1. Validate qubit count and gate schema.
2. Validate shot count and root seed.
3. Identify measured qubits in first-appearance order.
4. For each shot, instantiate a fresh simulator in the all-zero initial state.
5. Execute the gate sequence and collect measurement outcomes.
6. Aggregate bit-string counts and empirical probabilities.
7. Serialize a versioned JSON result.

## Result contract
- `schema_version`: result format identifier.
- `backend`: backend label.
- `num_qubits`, `shots`, `seed`: run configuration.
- `measured_qubits`: measurement order used in output bit strings.
- `counts`: outcome counts.
- `probabilities`: normalized empirical frequencies.
- `notes`: explicit limitations.

## Metrics
The distribution metrics normalize input weights first. Missing outcome keys are treated as zero probability. Both metrics are in [0, 1], where zero indicates identical distributions.

## Security and reliability
- JSON input is parsed as data; it is not evaluated as code.
- Input circuit validation occurs before simulation.
- Shot count is capped at one million to reduce accidental resource exhaustion.
- The CLI returns a nonzero status on invalid input.
- No network calls or external services are used.

## Acceptance criteria
- Reproducible results for equal seeds and inputs.
- Deterministic X measurement always returns `1`.
- Bell-state measurements are correlated (`00` or `11`) for the provided circuit.
- Invalid shots and missing measurements are rejected.
- Metrics handle normalization and reject negative/invalid weights.
