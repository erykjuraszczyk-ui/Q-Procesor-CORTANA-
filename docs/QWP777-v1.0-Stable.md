# QWP-777 v1.0.0 Stable — Technical Specification

## Objective
Finalize the source-tree Python API and JSON experiment-result contract for the QWP-777 educational simulator prototype.

## Included
- Repeated-shot experiments for selected Clifford circuits.
- CLI using JSON circuit configuration.
- Public API facade through `qwp777_api.run_circuit(config)`.
- Input and output contract validation.
- TVD and Hellinger distribution comparison metrics.
- Test suite, example circuits, migration notes, and release documentation.

## Result contract invariants
1. `sum(counts.values()) == shots`.
2. Probability keys match count keys.
3. Each probability equals `count / shots` within numerical tolerance.
4. Outcome bit strings match the length of `measured_qubits`.
5. Measured qubit indices are unique and in range.
6. `schema_version` remains `qwp777-experiment-1`; release and API versions are separate metadata.

## Stable release verification
The packaged test suite and included CLI examples are run locally during release assembly. See `TEST_REPORT.md` for recorded results. Those checks are not a substitute for cross-platform qualification or independent scientific validation.

## Non-goals and limitations
This package does not contain a physical quantum processor, FPGA bitstream, hardware driver, universal arbitrary-circuit simulator, physical noise model, or dynamic-circuit execution. The stabilizer backend remains a prototype for selected Clifford gates.
