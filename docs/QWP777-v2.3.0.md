# QWP-777 v2.3.0

QWP-777 v2.3.0 adds bounded stability/soak tests, current RSS sampling where procfs is available, and comparison of profiling reports for matching workloads. The public API remains source-compatible and the result schema stays `qwp777-experiment-1`.

This is a Python software prototype, not physical quantum hardware. Finite tests and performance diagnostics do not prove correctness for every possible circuit or prove the absence of memory leaks.
