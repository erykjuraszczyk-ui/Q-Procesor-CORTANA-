# QWP-777 v1.3.0

## Release scope
- New backend conformance comparison API in `qwp777_conformance.py`.
- Compare count dictionaries or result JSON payloads with total variation distance (TVD), Hellinger distance, and per-outcome probability deltas.
- Normalize distributions so differing shot totals can be compared.
- New CLI: `src/qwp777_compare.py result_a.json result_b.json`.
- API version 1.3; existing experiment result schema remains `qwp777-experiment-1`.

## CLI example
Run two experiments and save their result payloads:
```bash
python src/qwp777_experiment.py examples/bell.json -o /tmp/backend-a.json
python src/qwp777_experiment.py examples/bell.json --noise-probability 0.02 -o /tmp/backend-b.json
python src/qwp777_compare.py /tmp/backend-a.json /tmp/backend-b.json
```
The comparison expects matching `num_qubits` and `measured_qubits` order.

## Interpretation
- TVD is 0 for identical empirical distributions and 1 for disjoint distributions.
- Hellinger distance is 0 for identical distributions.
- `probability_delta_right_minus_left` shows the signed empirical probability change for each outcome.
- A small distance does not prove either backend is correct; shot noise, circuit differences, and backend implementation bugs remain possible.

## Limitations
This is a software prototype, not physical quantum hardware. The Qiskit Aer adapter is optional and runs on a classical simulator. The built-in noise option is synthetic measurement post-processing, not calibrated physical noise. This release does not claim universal arbitrary-circuit simulation for 777 qubits.
