# QWP-777 v1.1.0 — Technical Specification

## Goal
Improve validation quality by adding an exact, small statevector reference for unitary circuits and a consistent statistical comparison path from observed shot counts to ideal probabilities.

## Modules
- `qwp777_reference.py`: ideal computational-basis probabilities for supported unitary gates, maximum 12 qubits.
- `qwp777_statistics.py`: counts, empirical frequencies, and Shannon entropy in bits.
- `qwp777_differential_validation.py`: TVD/Hellinger comparison of empirical frequencies against the reference.
- `qwp777_api.py`: public API facade exposing the new helpers.

## Differential validation flow
1. Provide the unitary gate sequence, without measurement operations.
2. Compute ideal reference probabilities with the statevector oracle.
3. Provide observed counts in the same displayed bit-string order.
4. Normalize counts to empirical probabilities.
5. Compute TVD and Hellinger distance.

## Metric interpretation
TVD and Hellinger distance range from 0 to 1. A value of 0 means the distributions are identical; a larger value means greater discrepancy. Finite-shot empirical data can differ from ideal probabilities even when the simulator is behaving as intended.

## Constraints
- Reference oracle: 1..12 qubits.
- Reference unitary gates supported by the oracle: H, S, X, Z, CX, CZ.
- Measurement must be excluded from the reference unitary circuit.
- This reference oracle shares code lineage with the QWP project and is not an independent external implementation.
