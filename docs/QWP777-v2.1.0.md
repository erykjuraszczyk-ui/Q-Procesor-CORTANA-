# QWP-777 v2.1.0

## Scope
This minor release introduces host-specific performance diagnostics without changing the experiment result schema or existing API signatures.

## Profiling
`qwp777_profile.py` runs a circuit repeatedly and reports min/median/mean/max elapsed seconds plus Python `tracemalloc` peak allocation. The report includes the execution environment. These measurements are diagnostic only and carry no portable pass/fail target.

## Runtime information
`qwp777_runtime_info.py` emits JSON-compatible Python and OS information with best-effort memory information; unknown values are `null`. It does not install packages or collect network data.

## Validation
The release audit runs a small one-qubit smoke profile, checks the v2.1 API snapshot and historical v1.6 API contract, verifies regression baseline checksums and compares fixed-seed results with v2.0.0. Target-platform testing on Android/Termux still requires a user run on an actual Android device.
