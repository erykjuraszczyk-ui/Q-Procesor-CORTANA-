# QWP-777 v2.6.0 — release summary

## Goal

Provide a reproducible overview of regression and health evidence across multiple software releases, rather than inspecting each report manually.

## Components

- `src/qwp777_release_series.py`: validates supported report schemas, groups reports by release, extracts available summary metrics, compares adjacent supplied regression reports, and emits JSON and HTML.
- `tests/test_v2_6_release_series.py`: exercises cross-release failure detection, clean transitions, health review status, unknown schemas, and HTML escaping.
- `compatibility/api-v2.6.0.json`: new immutable public API snapshot.
- `regression/baselines/v2.6.0.json`: new versioned fixed-seed regression baseline with SHA-256 sidecar.
- `src/qwp777_release_audit.py`: now runs a smoke test for the release-series aggregator.

## Validation

The release uses the finite unit test suite and the unified release audit. The audit covers legacy/current API compatibility, historical and current regression baselines, baseline checksum, release comparison, signature self-tests, profiler/memory/benchmark/soak diagnostics, anomaly analysis, device comparison, and multi-release history aggregation.

## Limitations

The history tool summarizes provided JSON; it does not verify whether a report was honestly produced, rerun tests, or authenticate each report unless the caller separately validates a signed archive. Version comparisons are only as complete as the provided regression reports. Empirical distribution changes require context and review; they do not automatically imply a simulator bug.
