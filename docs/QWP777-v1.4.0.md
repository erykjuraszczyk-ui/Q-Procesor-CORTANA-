# QWP-777 v1.4.0

## Release scope
- Added outcome-wise Wilson score confidence intervals.
- Added approximate confidence intervals for right-minus-left empirical outcome probabilities.
- Comparison CLI now embeds `confidence_analysis` in its JSON output.
- Supported confidence levels: 80%, 90%, 95%, 98%, and 99%.
- API version 1.4; experiment result schema remains `qwp777-experiment-1`.

## Example
```bash
python src/qwp777_experiment.py examples/bell.json -o /tmp/a.json
python src/qwp777_experiment.py examples/bell.json --noise-probability 0.02 -o /tmp/b.json
python src/qwp777_compare.py /tmp/a.json /tmp/b.json --confidence-level 0.95
```

## Interpretation and limits
Wilson intervals describe sampling uncertainty for each outcome. The difference interval uses a normal approximation for independent proportions. Outcome-wise intervals are not simultaneous family-wise intervals. These calculations do not account for circuit mismatch, systematic backend errors, device drift, or incorrect implementations. A confidence interval is not proof of equivalence or correctness.
