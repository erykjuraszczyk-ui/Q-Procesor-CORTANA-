# QWP-777 v1.2.0

## Release scope
- Optional Qiskit Aer adapter for small circuits; Qiskit dependencies remain optional.
- Explicit synthetic independent bit-flip post-processing for sampled measurement outcomes.
- CLI option `--noise-probability P`, where `P` is between 0 and 1.
- Deterministic seeded noise and regression tests.
- API version 1.2; result schema remains `qwp777-experiment-1`.

## Examples
No noise (default):
```bash
python src/qwp777_experiment.py examples/bell.json
```

Synthetic 2% bit-flip noise:
```bash
python src/qwp777_experiment.py examples/bell.json --noise-probability 0.02
```

Optional external backend:
```python
import sys
sys.path.insert(0, "src")
from qwp777_qiskit_adapter import run_with_qiskit
result = run_with_qiskit(2, [
    {"gate": "H", "qubits": [0]},
    {"gate": "CX", "qubits": [0, 1]},
    {"gate": "MEASURE", "qubits": [0]},
    {"gate": "MEASURE", "qubits": [1]},
], shots=1000, seed=777)
print(result["counts"])
```
Install compatible `qiskit` and `qiskit-aer` packages separately to enable this optional adapter.

## Important limitations
The synthetic bit-flip option is outcome post-processing, not a physical noise simulation, calibrated device model, or quantum error-correction model. Qiskit Aer is an optional classical simulator; it is not quantum hardware. The adapter caps circuits at 30 qubits as a conservative guard, but practical resource use can be far lower depending on backend and circuit. The core stabilizer backend is intended for supported Clifford circuits. No claim is made that this package universally simulates arbitrary circuits on 777 qubits.
